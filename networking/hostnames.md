# Hostnames

## System hostname

The command `hostname` displays the system's hostname:

```bash
[root@localhost ~]$ hostname
localhost.localdomain
```

In this example `localhost` is the host's own name and `localdomain` is the domain, which means the network that it belongs to.

The command `hostnamectl` gives more information:

```bash
[root@localhost ~]$ hostnamectl
     Static hostname: (unset)                                 
  Transient hostname: localhost
           Icon name: computer
          Machine ID: c66ffaecff7e43a3a1c23ff480c4027d
             Boot ID: 1129dd0480404c298f0499855fe56d64
    Operating System: Rocky Linux 10.2 (Red Quartz)           
         CPE OS Name: cpe:/o:rocky:rocky:10::baseos
      OS Support End: Thu 2035-05-31
OS Support Remaining: 8y 8month 3d                            
              Kernel: Linux 6.12.0-211.16.1.el10_2.0.1.aarch64
        Architecture: arm64
```

| Hostname    | Description                     |
|-------------|---------------------------------|
| `Static`    | Persistent, it survives reboots |
| `Transient` | Assigned dynamically (DHCP)     |

The `Static hostname` is the hostname specified in `/etc/hostname`. In this case it's unset:

```bash
[root@localhost ~]$ cat /etc/hostname

```

If you modify `/etc/hostname`, the `Static hostname` displayed by `hostnamectl` will show the change:

```bash
[root@localhost ~]$ echo "rocky" > /etc/hostname
[root@localhost ~]$ hostnamectl
     Static hostname: rocky
  Transient hostname: localhost
           Icon name: computer
          Machine ID: c66ffaecff7e43a3a1c23ff480c4027d
             Boot ID: 1129dd0480404c298f0499855fe56d64
    Operating System: Rocky Linux 10.2 (Red Quartz)           
         CPE OS Name: cpe:/o:rocky:rocky:10::baseos
      OS Support End: Thu 2035-05-31
OS Support Remaining: 8y 8month 3d                            
              Kernel: Linux 6.12.0-211.16.1.el10_2.0.1.aarch64
        Architecture: arm64
```

You can modify the static hostname also with `hostnamctl hostname`:

```bash
[root@localhost ~]$ hostnamectl hostname hello
[root@localhost ~]$ cat /etc/hostname
hello
[root@localhost ~]$ hostnamectl
     Static hostname: hello
           Icon name: computer
          Machine ID: c66ffaecff7e43a3a1c23ff480c4027d
             Boot ID: 1129dd0480404c298f0499855fe56d64

```

## Name resolution

The stub resolver converts domain names to IP addresses and it determines where to look based on `/etc/nsswitch.conf`:

```bash
[user@rocky ~]$ cat /etc/nsswitch.conf 
# Generated by authselect
# Do not modify this file manually, use authselect instead. Any user changes will be overwritten.
# You can stop authselect from managing your configuration by calling 'authselect opt-out'.
# See authselect(8) for more details.

# In order of likelihood of use to accelerate lookup.
passwd:     files systemd
shadow:     files systemd
group:      files [SUCCESS=merge] systemd
hosts:      files  dns myhostname
services:   files
netgroup:   files
automount:  files

aliases:    files
ethers:     files
gshadow:    files systemd
networks:   files dns
protocols:  files
publickey:  files
rpc:        files
```

By default the stub resolver is set to look first at files. The file that it looks at is `/etc/hosts`:

```bash
[user@rocky ~]$ grep -v '^#' /etc/hosts
127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
```

If the domain name is not found in `/etc/hosts`, then the stub resolver uses a DNS name server, which is set in `/etc/resolv.conf` by NetworkManager:

```bash
[user@rocky ~]$ cat /etc/resolv.conf 
# Generated by NetworkManager
search fritz.box
nameserver 192.168.178.2
nameserver fd17:625c:f037:2::3
```

> Don't edit this by hand! Use `nmcli` or `nmtui` to change the configuration!
